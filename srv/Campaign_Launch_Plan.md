> We're building a dedicated game server node for the community, funded by the community.

## What Is This?

We're crowdfunding a powerful dedicated server to join the haven.stream network as its new **primary game node** — purpose-built to host the heaviest modpacks and largest game servers for the community.

This machine runs 24/7, managed through Pterodactyl, with full monitoring and automated backups. It slots into an existing infrastructure that already hosts Minecraft servers — this upgrade brings dramatically more power to the table.

## How the Money Works

- **0% platform fee** (Ko-fi) — only standard payment processing (~3%)
- **100% goes to hardware** — ongoing costs covered by the operator
- **Full transparency** — running total in Discord, weekly updates, itemized receipt after purchase
- **60-day campaign** — at the end, we buy the build matching the highest tier reached
- **If we don't hit $300**, everyone gets a full refund

## How This Fits Into Haven.stream

This isn't a standalone project — it's the next node in an existing server network. Haven.stream already runs Minecraft servers with full infrastructure: Pterodactyl management, automated backups, monitoring, VPN-secured admin access, and subdomain-based routing.

The crowdfunded machine becomes the **primary game node** — the most powerful machine in the cluster, dedicated to hosting the heaviest modpacks and largest servers. Existing nodes cascade to lighter workloads.

Your donation doesn't just buy hardware. It powers a server that's backed by real infrastructure, real monitoring, and real admin commitment.
