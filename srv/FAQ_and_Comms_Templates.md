# ❓ Haven.stream Community Server — FAQ

> Everything you might want to know before donating or playing.

---

## About the Project

**What is this?**
A community-funded dedicated game server node for haven.stream. The money goes to hardware. The operator covers all ongoing costs (electricity, internet, domain).

**What is haven.stream?**
A self-hosted game server network running Minecraft (and eventually more). It uses Pterodactyl for server management, automated backups, and full monitoring. The crowdfunded machine becomes the most powerful node in this network.

**Who runs this?**
One person — the server operator. This isn't a company or a business. It's a community project.

**Is this a subscription?**
No. This is a one-time crowdfunding campaign. You donate once, your rewards are permanent.

## The Server

**What games will it run?**
Minecraft first (vanilla and modded). Other games as community interest and resources allow.

**How do I connect?**
Minecraft servers are accessible via subdomains: `servername.haven.stream`. Just type it into your Minecraft client — no IP addresses to remember, no port numbers.

**Is there a whitelist?**
Depends on the server. Some community servers may be whitelisted, others may be open. This is decided by community vote (Builder+ donors).

**Will there be modded servers?**
Yes! The primary purpose of this machine is to host heavy modpacks that the existing hardware can't handle.

**What's the uptime?**
This is a home-hosted community project, not a datacenter. We aim for 24/7 operation with automated monitoring and alerting, but we can't guarantee 100% uptime. Scheduled maintenance is announced in advance.

## Dedicated Server Instances

**Who gets a dedicated server?**
Architect ($200+), Keystone ($350+), and Cornerstone ($500+) donors.

**What can I run on my dedicated server?**
Any game the hardware can reasonably handle. Minecraft (vanilla or modded), Valheim, Terraria, Satisfactory, etc. We'll work with you on setup.

**How much resources do I get?**

| Tier | RAM | Disk Space |
|------|-----|-----------|
| Architect ($200+) | 8 GB | 50 GB |
| Keystone ($350+) | 12 GB | 75 GB |
| Cornerstone ($500+) | 16 GB | 100 GB |

CPU is allocated dynamically — your server gets what it needs.

**Do I manage my own server?**
Yes! You get Pterodactyl panel access to start, stop, configure, upload mods, and manage your server. You don't need to know Linux — the panel handles everything through a web interface.

**Can my friends play on my dedicated server?**
Absolutely. It's your server — invite whoever you want.

**What if I stop using my server?**
After 60 days of inactivity, we'll check in with you via DM. If you don't respond within 14 more days, the instance is archived (files saved, resources freed). You can reactivate anytime.

**What's not allowed?**
No crypto mining, no illegal content, no attacking other systems, no reselling access. See the full [Acceptable Use Policy](Acceptable_Use_Policy_Version_A_Public.md).

## Money & Transparency

**Where does the money go?**
100% to server hardware (after payment processing fees). Itemized receipts are posted after purchase.

**How do I track progress?**

No. The operator receives no compensation and covers ongoing costs out of pocket.

## After the Campaign

**When will the server be ready?**
Approximately 3-4 weeks after the campaign closes. Follow #server-updates for build progress.

**What if hardware prices change?**
We adjust the build to stay within budget and explain what changed. Transparency is the priority.

Potentially — for community branding (mascot, logo, merch) or future hardware upgrades. Any future campaign will be separate and clearly communicated.
