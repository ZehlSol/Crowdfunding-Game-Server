# 🔧 Post-Campaign — Build & Launch Timeline

> What happens after the campaign closes. Follow along in #server-updates!

---

## The Plan

| Phase | Timeline | What's Happening |
|-------|----------|-----------------|
| 🛒 **Ordering** | Days 1-3 | Components ordered. Itemized receipt posted. |
| 📦 **Arrival** | Days 4-10 | Parts arrive. Unboxing photos in #server-updates! |
| 🔧 **Assembly** | Days 10-12 | Hardware assembled and POST verified. Build photos shared. |
| 💻 **OS & Software** | Days 12-16 | Debian installed. Pterodactyl Wings configured. Node joins the haven.stream network. Monitoring goes live. |
| 🧪 **Testing** | Days 16-19 | Stress testing, burn-in, and benchmarks. Results shared in #server-updates. |
| 🎮 **Community Servers Live** | Day ~20 | Community game servers go online. Everyone can connect! |
| 🖥️ **Dedicated Instances** | Days 20-25 | Architect, Keystone, and Cornerstone donors get their instances set up. Panel access DMs sent. |

**Total: approximately 3-4 weeks from campaign close to servers live.**

---

## After Launch

Once the server is live, here's what ongoing operations look like:

- **Automated backups** — your worlds and data are backed up automatically
- **24/7 monitoring** — Grafana dashboards track CPU, RAM, disk, temperatures, and per-server metrics
- **Critical alerts** — if something goes wrong, the admin is notified immediately via Discord
- **Updates & maintenance** — game servers and modpacks are updated as needed, with advance notice for any downtime

The server is built to run reliably with minimal intervention. That's the whole point.
