## 💡 FAQ

**Q: What happens if we land between milestones?**
A: We purchase at the last fully-funded milestone. Any surplus rolls toward the next goal if the campaign continues, or is held transparently for future upgrades.

**Q: Why not start with the best parts?**
A: Every tier is a complete, functional server. If we only raise $500, you still get a solid 8-core machine. The ladder ensures no donation is wasted.

**Q: Why AM5?**
A: AMD supports AM5 through 2027+. Every CPU on this ladder fits the same socket. The platform is proven, reliable, and has a clear upgrade path.

**Q: Why Micro-ATX instead of Mini-ITX for the compact build?**
A: Mini-ITX boards only have 2 RAM slots, which would cap us at 96 GB and cut our storage slots in half. Micro-ATX keeps all 4 RAM slots (128 GB), all 3 M.2 storage slots, and better 5GbE networking — with zero performance compromise. The case is still dramatically smaller than a full tower.

**Q: Why 4 sticks of RAM instead of 2?**
A: For a server, memory capacity matters far more than memory speed. 4×32 GB at DDR5-5600 gives us 128 GB — enough to run 12+ game servers simultaneously. The small speed reduction vs 2 sticks at DDR5-6000 has negligible impact on server workloads. We use a matched 4-stick kit for guaranteed stability.

**Q: What about the original ATX parts when we go compact?**
A: The ATX motherboard and full-tower case are replaced. Those parts can be sold or repurposed by the community.
