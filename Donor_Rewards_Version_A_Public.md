## ❓ FAQ

**Do rewards stack?**
Yes! A Cornerstone ($500+) gets everything from every tier below — the donor wall listing, insider updates, voting rights, reserved slots, spawn monument, naming rights, private channels, AND the premium 16 GB dedicated server.

**How long do rewards last?**
As long as the server is running. This is a community project, not a subscription.

**Can I choose any game for my dedicated server?**
Any game that the hardware can reasonably handle. We'll work with you on setup. If it's something exotic, we'll figure it out together.

**What if the server is at capacity?**
New dedicated server instances may be queued until resources are available. We'll always be transparent about this.

**Is there a code of conduct?**
Yes. All servers (community and dedicated) are subject to reasonable use policies. No crypto mining, no illegal content, nothing that degrades the experience for everyone else.
