# 🛡️ Haven.stream — Acceptable Use Policy

> These rules apply to all community servers and donor-provided dedicated server instances.
> By using any haven.stream server, you agree to these terms.

---

## The Short Version

1. Don't be a jerk.
2. Don't break things for other people.
3. Don't do anything illegal.
4. If you have a dedicated server, keep it reasonable.

---

## Community Servers (Shared)

These are servers run by haven.stream for the whole community (e.g., the community Minecraft server).

### Expected Behavior
- Be respectful to other players
- No griefing, harassment, hate speech, or targeted toxicity
- No exploits that degrade server performance (duplication glitches, lag machines, etc.)
- Follow any game-specific rules posted for that server

### Consequences
- **First offense (minor):** Warning via Discord DM
- **Second offense:** Temporary ban (duration depends on severity)
- **Serious offense (hate speech, doxxing, threats, etc.):** Immediate permanent ban, no warning

---

## Dedicated Server Instances (Donor-Provided)

Architect ($200+), Keystone ($350+), and Cornerstone ($500+) donors receive their own game server instances with Pterodactyl panel access.

### What You CAN Do
- Run any game the hardware can reasonably handle
- Install mods, plugins, and custom configurations
- Invite whoever you want to play on your server
- Start, stop, restart, and manage your server through the panel
- Upload files, edit configs, and manage backups through the panel

### What You CANNOT Do
- **No cryptocurrency mining** — instant removal, no exceptions
- **No illegal content** — this includes pirated software, illegal media, or anything that violates US law
- **No resource abuse** — don't run processes designed to consume maximum CPU/RAM indefinitely (stress tests, hashcat, etc.)
- **No attacking other systems** — no port scanning, DDoS tools, botnets, or any offensive security tools
- **No services that degrade the experience for others** — if your instance is causing lag or instability on other servers, we'll work with you to fix it. If it continues, the instance may be suspended.
- **No reselling access** — your server is for your community, not a commercial hosting business

### Resource Expectations

Your instance has allocated RAM and disk space based on your tier:

| Tier | RAM | Disk |
|------|-----|------|
| Architect | 8 GB | 50 GB |
| Keystone | 12 GB | 75 GB |
| Cornerstone | 16 GB | 100 GB |

CPU is allocated dynamically — your server gets what it needs when it needs it. If the system is under heavy load, all instances share CPU fairly.

If you need more disk space, ask — we may be able to accommodate depending on available storage.

### Inactivity Policy

If your dedicated server hasn't been started in **60 days**, we'll send you a friendly check-in DM. If there's no response after **14 more days**, the instance will be archived (files preserved, resources freed). You can request reactivation at any time — your data is never deleted without explicit communication.

### Instance Suspension

If your instance violates this policy:
1. We'll contact you to explain the issue and work on a fix
2. If the issue isn't resolved within a reasonable time, the instance may be temporarily suspended
3. For severe violations (crypto mining, illegal content, attacks), suspension is immediate

Suspended instances can be appealed by contacting the admin directly. We're not trying to be heavy-handed — we just need the server to work well for everyone.

## Privacy

- We do not sell or share any personal information
- Donation amounts are displayed on the Ko-fi supporter wall (you can donate anonymously on Ko-fi if you prefer)
- Discord usernames are used for the donor wall unless you request otherwise
- Server logs (connection IPs, chat logs) are collected for moderation and troubleshooting only
- We don't monitor the content of your dedicated server instance unless a complaint is filed or a policy violation is suspected

## Changes to This Policy

We may update this policy as the project evolves. Changes will be announced in Discord. Continued use of haven.stream servers after a policy change constitutes acceptance.
